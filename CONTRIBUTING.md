# Contributing

This is a personal portfolio project. Please open an issue to discuss proposed changes before submitting substantial contributions.

## Local development

Follow the [README](README.md) and [configuration guide](docs/configuration.md).

## Pull requests

- Keep changes focused and describe the motivation.
- Do not include secrets, personal data, or client-confidential materials.
- Run `npm run build:frontend` and check backend JavaScript syntax before submitting.
- Document any new environment variables or API routes.
- Prefer descriptive commit messages and include verification steps in the PR description.

## Code of conduct

Be respectful and constructive in issues and reviews.
